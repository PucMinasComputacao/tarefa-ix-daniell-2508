## 📌 Descrição
Este projeto consiste em uma aplicação web simples que simula um mini eCommerce, exibindo produtos em formato de cards.

Os produtos são carregados a partir de um objeto JSON e renderizados dinamicamente utilizando JavaScript e manipulação do DOM.

---

## ⚙️ Funcionalidades
- Listagem de produtos em cards
- Filtro por nome (campo de busca)
- Filtro por categoria
- Visualização de detalhes do produto
- Destaque de produtos
- Renderização dinâmica via DOM

---

## 🧠 Tecnologias utilizadas
- HTML
- CSS
- JavaScript (DOM)
